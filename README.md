# Assessment API - Abhishek

Express API that reads smart-contract data from Ethereum Sepolia using JSON-RPC.

## Endpoint
GET /AbhishekApiTest

## Response
Returns the network, chain ID, contract address, and contract name.

## Run locally
```bash
npm install
npm start
```

## Health check
GET /api/health

## Technologies
Node.js, Express, Ethereum JSON-RPC, Ethereum Sepolia
